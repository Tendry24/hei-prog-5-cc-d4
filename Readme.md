# 🐍 HEI Snake Game
*(this a project build to prepare last exam of clean code)* 
A simple console-based **Snake Game** written in TypeScript, built to practice **Clean Code principles** and design patterns such as **Factory**, **Builder**, **State**, and **Strategy**.



## Project Context

This game was created as a learning project to apply Clean Code principles:

- **DRY**: Don’t Repeat Yourself
- **KISS**: Keep It Simple, Stupid
- **YAGNI**: You Aren’t Gonna Need It
- **Naming**: Clear and meaningful names
- **Factory Pattern**: For food creation
- **Builder Pattern**: To build the initial snake
- **Strategy Pattern**: To decouple the movement logic
- **State Pattern**: To manage game states (Menu, Running, Game Over)

## How to Play

- The game is played on a **10x10 grid** in the console.
- The snake moves automatically.
- You can control its direction using the keyboard:

ZQSD
| Key | Direction |
|-----|-----------|
| Z   | Up        |
| S   | Down      |
| Q   | Left      |
| D   | Right     |
